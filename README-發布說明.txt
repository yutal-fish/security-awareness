網路與資訊安全作業｜發布與繳交流程

一、先個人化首頁
1. 首頁已填入學號與姓名：413430066-余亭均。
2. 若要修改姓名或學號，用記事本或 VS Code 開啟 index.html，將「413430066-余亭均」替換成正確資料並儲存。

二、預覽網站
直接以瀏覽器開啟 index.html。從導覽列測試首頁、密碼防護、辨識釣魚、隱私安全，以及「實用資源」底下的兩個子選項。網站使用相對路徑，請保留整個資料夾及 assets 圖片資料夾。

三、發布成網址（以 GitHub Pages 為例）
1. 登入或註冊 GitHub，建立一個新的公開 Repository，例如 security-awareness。
2. 將本資料夾內所有檔案和 assets 資料夾上傳至 Repository 根目錄（不要只上傳 index.html）。
3. 開啟 Repository 的 Settings → Pages，在 Build and deployment 選擇 Deploy from a branch；Branch 選 main、資料夾選 /(root)，按 Save。
4. 等待 GitHub Pages 部署完成，頁面會顯示網址，通常是 https://你的帳號.github.io/security-awareness/ 。用無痕視窗開啟，逐頁確認圖片、選單和外部連結正常。
5. 若學校或老師提供指定發布平台，依其規則上傳整個網站資料夾並使用平台產生的公開網址。

四、繳交
將「發布完成後的網址」貼到 iClass 作業欄位；若作業要求文字檔，將網址寫入「繳交網址.txt」後上傳。注意：本機檔案路徑不是公開網站網址。

本範例的外部參考連結指向 CISA、NIST、NCC；外部網站內容及網址可能變動，繳交前請點開確認。
